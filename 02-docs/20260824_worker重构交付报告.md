## 3. 各期要点

### M1 — 框架落地
- **Skill 契约**（`runtime/skill.py`）：`SkillContract / SkillContext / SkillResult / TriggerSpec`，capture/parse（/transcribe/compose/index）钩子，executor 是唯一编排者。
- **executor 通用编排**：`run_job_resume` 平移 + 参数化，状态机 CAS、断点续跑、SFTP 回传、微信回调统一承载。
- **认领原子性 / 心跳 / 租约**：SKIP LOCKED + CAS，双 worker 并发只一人得手；心跳刷新 claimed_at 防被抢。
- **启动连通性自检**（§4.4）：Groq/PG/SFTP 三通道启动即验，失败仅告警不阻塞。
- **echo skill**：pending→ready 端到端 + step_logs 全程有迹。

### M2 — Skill 迁移
- **`_shared` 四库**：fetcher（URL 抓取级联）/ asr（Groq·tingwu·本地 whisper）/ llm（robust_json_parse）/ render（真实卡片 PNG）+ storage（路径约定不动）。
- **四 skill**：xiaoyuzhou（音频三层降级解析）/ wechat_article / upload（SFTP 拉取 + paste 分流，含瞬时失败熔断）/ generic（"*" 兜底）。
- **删除旧引擎**：`inflow_core/` 整目录删除，唯一真源 = 本仓库。

### M3 — 投产加固
- **skill_usage 记账**：`RecordingLLM` 包装 `ctx.llm` 无感采集 tokens（skill 零改动）；`_asr.json` 读 audio_seconds；job 到 ready/failed 幂等写表（`ON CONFLICT DO NOTHING`，断点续跑不重复记）；费率折算 `utils/rates.py`（默认按 2026-08 市价估算，投产前按账单覆盖）。
- **观测告警**（`scheduler/observer.py`，独立 asyncio task，5min 巡检）：进度停滞>10min → WARNING；租约超时分级（本机 ERROR=心跳停 / 他机 WARNING=待回收）；日失败率>30% → ERROR。**单检查异常仅告警不崩**——观测循环本身不是故障点。
- **Windows 7x24**：`deploy/windows/install-service.ps1` 用 NSSM 注册 `inFlowWorker`（开机自启 + 崩溃 5s 自动重启）；`run-worker.ps1` 手动跑；启动时 `reclaim_own_host` 自动清理本机遗留租约（重启安全）。
- **云端 SQL**（§8/§12）：`skill_usage.sql` 建表（worker 只写不建）、`quota_check.sql` 免费额度 10 条/人/天核算、`alerts.sql` 云端侧聚合告警（停滞/租约/失败率/worker 失联）。

### M4 — B 形态试点
- **claude_runner 适配器**：SKILL.md 指令 → 同一 SkillContract（capture/parse 各跑一次 `claude -p --output-format stream-json` 子进程会话），stream-json 流解析 → 产物 normalize 为 RawCapture/ParsedContent。**executor 无感知，A/B 可互换**（§5.4）。
- **会话异常分级**：CLI 不可用 / 超时（kill 子进程）/ 非零退出 / 无产物——调用方捕获后**自动退回 A 形态**。
- **generic 升级 B**：`ENABLE_GENERIC_B=true` + claude CLI 可用时生效；CLI 缺失回退 A。指令包 `generic/SKILL.md`。
- **成本口径**：每次会话 usage 计入 `ctx.usage` → M3 `skill_usage` 出账，A/B 单均成本可对比。

## 6. 部署步骤（生产上线）

### 6.1 云端（腾讯云）——按顺序
1. `psql ... < deploy/cloud/skill_usage.sql`（建表，worker 只写不建）
2. 按需配置 `quota_check.sql`（免费额度核算）+ `alerts.sql`（观测告警推送）
3. §12 配合项：PG 5432 / SFTP 22 白名单 = worker 家庭公网 IP；微信推卡联调

### 6.2 Worker（本地 Windows 家用机，7x24）
```powershell
# 一次：venv + 依赖 + playwright + .env.local-worker + config_store.json
# 安装为服务（管理员）：
cd deploy\windows
.\install-service.ps1          # NSSM 自启 + 崩溃重启
```
> 家用宽带动态公网 IP 变更 → worker 断线退避自愈 + M3 观测告警兜底；频繁可平滑切出站隧道（Tailscale/WireGuard，架构不变式只出站天然兼容）。
