# 技术方案 · 微信 Bot 解析完成后推送精华卡 PNG

> 生成于 2026-06-26，基于产品讨论与代码分析

---

## 背景

当前微信 Bot 在用户提交 URL 后只回复一句「✅ 已加入队列」，解析完成后没有任何后续反馈。本方案在 pipeline 完成后，自动向用户推送一张播客精华卡 PNG 图片，满足「快速概览 + 激发分享欲」的移动端诉求。

---

## 整体链路

```
用户发 URL
  → Bot 提交 /api/ingest/url
  → 收到 job_id，写入 wechat_callback_queue（附 asr_json_path）
  → 返回「已加入队列」

Pipeline 完成 (run_transcribe → _asr.json 落盘 → run_index → status=ready)
  → wechat_callback_queue.status 更新为 'ready'

Bot 轮询协程（每 5s）
  → 发现 status='ready' 的记录
  → 读取 {job_id}_asr.json（含 text / duration 字段）
  → 调用 LLM（Sonnet 4.6），注入提示词 + 转录文本
  → LLM 输出完整 HTML（单文件，含 CSS/JS）
  → HTML 落盘 → playwright 全页截图 → PNG 落盘
  → ilink API 发送图片消息
  → 标记 status='sent'

already_exists 情况（文章已解析）
  → asr_json_path 仍有效 → 直接渲染发送
```

## 渲染方案：LLM 提取结构化 JSON + Jinja2 模板渲染

> **2026-06-27 更新**：经国内多款顶级模型测试（DeepSeek-V3、Qwen2.5-Coder-32B），纯靠提示词让 LLM 生成完整 HTML 效果不稳定，改回模板方案。

| 方案 | 稳定性 | 视觉一致性 | 维护成本 |
|------|--------|-----------|---------|
| ~~LLM 生成完整 HTML~~ | ~~不稳定~~ | ~~每次不同~~ | ~~提示词迭代~~ |
| **LLM 提取 JSON + Jinja2 模板** | **稳定可控** | **品牌风格统一** | **改模板改样式** |

选 **JSON + 模板**，理由：
1. LLM 只负责"理解内容"（JSON 提取），不负责"写 HTML"——更可靠
2. 视觉风格由 `podcast_card_template.j2` 统一控制，品牌一致性强
3. 模板和 prompt 均可独立迭代，分工清晰

## LLM 调用规格

| 项 | 值 |
|---|---|
| 模型 | 全局 `llm_service` 配置（默认 `deepseek-chat`） |
| 提示词 | `app/prompts/s4/card_extract_asr.md` |
| 用户输入 | ASR 转录文本（最多 10,000 字符，首 7k + 末 3k 采样） |
| 预计输出 tokens | ~2,000–3,000（结构化 JSON） |
| max_tokens | 3000 |
| 生成耗时 | ~5–15s |

### 提取字段（`card_extract_asr.md` 输出 JSON）

```json
{
  "title": "播客标题",
  "host_name": "主播姓名",
  "ep": "EP69 / Vol.12 / 空字符串",
  "category": "主题分类",
  "tags": ["标签1", "标签2", "标签3"],
  "core_quote": "一句话精华",
  "key_points": ["观点1", "观点2", "观点3"],
  "guest_name": "嘉宾姓名 或 null",
  "guest_role": "嘉宾身份 或 null",
  "guest_emoji": "👨 / 👩 / null",
  "quotes": ["金句1", "金句2"],
  "book": "推荐书目 或 null",
  "optional_block": { "type": "list/steps/pills/compare", ... }
}
```

> ASR 文本超 10,000 字时截取首 7k + 末 3k，覆盖开场介绍与结语。

## 需要改动的模块（5 处）

### 1. DB Migration — 新增回调队列表

文件：`app/core/migrations/017_wechat_callback_queue.sql`

```sql
CREATE TABLE wechat_callback_queue (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    job_id            UUID NOT NULL,
    article_id        UUID REFERENCES articles(id) ON DELETE CASCADE,
    wechat_account_id UUID NOT NULL,
    sender_id         TEXT NOT NULL,
    context_token     TEXT,
    asr_json_path     TEXT NOT NULL,              -- {job_id}_asr.json 绝对路径
    status            TEXT NOT NULL DEFAULT 'pending',  -- pending | ready | sent | failed
    card_path         TEXT,                       -- 生成的 PNG 文件路径
    error             TEXT,
    created_at        TIMESTAMPTZ DEFAULT NOW(),
    sent_at           TIMESTAMPTZ
);
CREATE INDEX ON wechat_callback_queue (status, created_at);
CREATE INDEX ON wechat_callback_queue (job_id);
```

同步新增 SQLAlchemy model：`app/core/models/wechat_callback.py`

### 2. `app/s4_compose/card_renderer.py` — 新管道：ASR → JSON → Jinja2 → PNG

**核心流程（`render_podcast_card_from_asr`）：**

```text
_asr.json
  ├─ transcript (text)   ─→ _llm_extract_from_transcript()
  └─ duration (秒)        ─→ duration_min

LLM 返回 JSON           ─→ _build_card_data_from_asr()
                                        ↓
                              CardData dataclass
                                        ↓
                            podcast_card_template.j2 (Jinja2)
                                        ↓
                              HTML 落盘 → Playwright → PNG
```

**关键函数：**

| 函数 | 职责 |
| --- | --- |
| `_llm_extract_from_transcript(transcript)` | 调用 LLM，转录文本 → JSON dict |
| `_build_card_data_from_asr(llm_fields, duration_min, source)` | JSON → CardData |
| `render_podcast_card_from_asr(job_id, asr_file_path, *, source_platform)` | 主入口 |

**签名变化：** 新增可选参数 `source_platform`，`bot.py` 调用时传入 `job.source_platform`。

### 4. `extensions/wechat/bot.py` — 四处改动

**A. `add_article` 返回 `job_id`**（三元组）

## 已确认决策

| 项 | 决策 |
|----|------|
| 渲染方式 | LLM 生成完整 HTML + playwright 全页截图 |
| LLM 模型 | `claude-sonnet-4-6` |
| 提示词位置 | `app/prompts/s4/20250413-播客访谈记录生成网页Prompt.md` |
| 输入数据 | `{job_id}_asr.json` → 取 `text` + `duration` 字段 |
| 截图宽度 | 750px（全页高，WeChat 支持长图） |
| 图片/HTML 落盘 | `app/prompts/s4/cards/{job_id}.{html,png}` |
| 图片大小 | 对标微信上限 2MB，长图无高度限制 |
| 字体 | LLM 生成 HTML 自带 Google Fonts / 系统字体 fallback |
| 已存在文章 | `already_exists` → asr_json_path 仍有效，直接渲染发送 |
| 处理中文章 | `already_processing` → 正常入队，pipeline 完成后推送 |
| 轮询间隔 | 5s（asyncio 协程，零额外进程） |
| 不再需要 | `podcast_card.html` Jinja2 模板（废弃） |
