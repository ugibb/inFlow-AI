## 1. Git 同步状态（本机，已由 Claude 完成 ✅）

当前 `main` 分支上，**本地 = GitHub = 腾讯云代码托管(cnb.cool) = `7dc8904`**，三端已同步。

下次改动后的本机提交流程（Git Bash 执行）：

```bash
# 提交
git add -A
git commit -m "feat: 说明这次改了什么"

# 推到全部远端：origin 配置了 GitHub(ssh) + cnb.cool(腾讯云, https) 两个 pushurl
git push origin main
```

> 若 push 输出「已更新 refs」后进程迟迟不退出（连接收尾挂起），属正常现象：用下面命令确认两端 ref 都已更新即可，Ctrl+C 退出不影响已送达内容。

确认两端都到最新：

```bash
# GitHub（origin fetch 走它）
git ls-remote origin refs/heads/main

# 腾讯云代码托管 cnb.cool（URL 从配置读取，避免泄露 token）
CNB_URL=$(git config --get-all remote.origin.pushurl | grep cnb.cool)
git ls-remote "$CNB_URL" refs/heads/main
```

两者输出都应指向目标 commit（本次为 `7dc8904...`）。
