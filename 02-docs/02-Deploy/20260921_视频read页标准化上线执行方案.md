### 0.2 视频站内播放——本地方案（`25539bd` + inFlow-local `local-media`）

**思路**：与小宇宙音频外链同机制——可播地址存 `articles.media_url`，read 页统一播放器直连。
小宇宙存 CDN 签名外链；视频存 **worker 本地音轨外链** `http://<局域网IP>:8788/audio/{job_id}`。

- worker（inFlow-local）：
  - `framework/transport/local_media.py`（新）：stdlib HTTP 服务（默认端口 8788），仅音频扩展名白名单、
    支持 HTTP Range/206（进度条拖动）、路径穿越防御
  - video job 到 ready 前把本地音轨外链**覆写 media_url**；服务未启/音轨缺失 → 保留平台页地址（前端视为不可播）
  - 启动 reconcile：家宽 DHCP 换 IP 后批量改写 `*/audio/*` 外链前缀
  - 设置开关：`LOCAL_MEDIA_SERVER`（默认 true）、`LOCAL_MEDIA_PORT`（默认 8788）
- 云端前端（inFlow-AI `25539bd`）：
  - `playableMediaUrl = media_url ≠ url`：视频 capture 期 media_url 是平台页地址（== url）不算可播
  - 视频卡与播客卡合并为**统一播放卡**：同一套播放器（进度/倍速/静音），转录句点选跳转、
    逐句跟播、章节跳转随 `playerReady` 激活；另有「看画面」入口跳原平台
  - 不可播（老数据 / worker 服务未启 / 外网访问）→ 自动降级「去原平台观看」（播放器 onError 兜底）

**边界（已确认接受）**：音轨仅局域网可达（家宽无公网 IPv4）；外网打开 read 页时播放器加载失败即降级跳原平台。
将来站点上 HTTPS 后 `http://` 音轨链接会被混合内容策略拦截——届时需给 worker 服务配 HTTPS 或换方案。

## 7. 风险与备注

- 本地音轨服务只暴露 `04-output` 下的音频扩展名文件，无目录列表；`/audio/{job_id}` 的 job_id 做 UUID
  校验防路径穿越；无鉴权（局域网内可匿名拉取音轨——家用环境已接受）
- CVM 出网访问不了 worker（家宽无公网 IPv4）→ 云端只存外链字符串，从不代理音频流量，不占 5Mbps 带宽
- worker 与浏览器不在同一局域网（如服务器中转场景）时永远走降级，功能无损
- 截图画廊数据源是 SFTP 回传的 `03_display/{job_id}_NNN.png`；无截图自动隐藏
