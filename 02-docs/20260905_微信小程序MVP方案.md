# 微信小程序 MVP 方案（浏览 + 阅读）

> 日期：2026-09-05
> 状态：已确认，实施中
> 范围：原生微信小程序，个人主体，MVP = 浏览 + 阅读，后端零改动

## 1. 背景与目标

inFlow-ai Web 端（Next.js + FastAPI + PostgreSQL，线上 `https://inflow.huituai.site`）已支持响应式 H5。目标是在微信内直接使用 inFlow：登录、瀑布流浏览、平台/主理人筛选、语义/关键词搜索、阅读（摘要/要点/章节/转录/原文）、分享卡片。

已确认约束：

- **个人主体、账号未注册** → 不能用 web-view（个人主体无权限），必须原生开发；开发期用「测试号」AppID 先行，注册后替换 `project.config.json` 一行即可
- **后端零改动**：API 纯 Bearer Token（无 cookie/CORS 问题），图片代理 `GET /api/images/proxy?url=` 无需鉴权，全部现成复用

## 2. 核心决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 位置 | 新增 `03-src/miniprogram/`，原生 WXML/WXSS/TS | 与 frontend 平级；运行时零 npm 依赖，工具链最稳 |
| TS 编译 | `useCompilerPlugins: ["typescript"]` | 微信开发者工具直接编译 .ts，无需本地构建步骤 |
| 滚动 | 页面级滚动（onPullDownRefresh + onReachBottom） | 原生下拉刷新/触底加载更可靠，长列表性能更好 |
| 瀑布流 | 翻译 Web「估算高度 + 塞最短列」算法，手机 2 列/宽屏 3 列 | 与 Web 端视觉一致，按发布时间从左到右 |
| Markdown | 自写简易渲染器 `md-view` 组件 | towxml 停更风险 + 包体大；后端结构化接口留二期 |
| 精读 HTML | MVP 隐藏该 tab | iframe 渲染的完整 HTML 小程序无法承载（个人主体无 web-view） |
| 图片 | `utils/image-url.ts` 唯一改写点 `resolveImage()` | 防盗链外链（微信/小红书/抖音 CDN）必须走后端代理 |
| tabBar | 2 个：首页(library) + 我的(me) | MVP 只有一个浏览面；me 承载登出 |
| 登录态 | `wx.setStorageSync('inflow_token')` + 启动 `/api/auth/me` 校验一次 + 401 统一拦截 | 与 Web localStorage 天然隔离；30 天 JWT 静默复用 |

## 4. 接口对照（全部现成）

| 用途 | 接口 |
|---|---|
| 登录 | `POST /api/auth/login {username,password}` → `{access_token(JWT 30天), user}` |
| 校验登录 | `GET /api/auth/me` |
| 列表 | `GET /api/articles?page&page_size=24&search&search_mode=semantic\|keyword&source_platform&author&sort=published_at` |
| 筛选数据 | `GET /api/articles/platforms`、`GET /api/articles/authors` |
| 详情 | `GET /api/articles/{id}`（含 clean_content + content_blocks 各 tab 存在性快照） |
| 章节/转录 | `GET /api/articles/{id}/chapters`、`GET /api/articles/{id}/transcript`（懒加载） |
| 图片代理 | `GET /api/images/proxy?url=<外链>`（无需鉴权，白名单 mmbiz.qpic.cn/xhscdn/douyinpic 等） |

阅读页 tab 显示 = 后端 `content_blocks.{key}.applicable` 驱动：原文/AI 解析恒显，章节 audio+article，转录仅 audio，精读隐藏。

## 5. 风险与对策

1. **个人主体内容类审核**（最大风险）：以「工具 > 效率」类目提交，名称/简介规避「资讯/媒体/社区」字样，截图证明全部内容在登录墙后、用户自建、无 UGC
2. **markdown 内嵌防盗链图**：md-view parse 阶段强制过 resolveImage，与封面共用同一函数
3. **代理图冷加载慢/图源失效**：卡片 image binderror → 渐变占位；lazy-load
4. **渲染器覆盖不足**：表格/嵌套列表降级为纯文本段落不丢内容，二期切后端结构化接口
5. **朋友圈单页模式**：无 tabBar、交互受限，阅读主路径可用即可
