# 精华卡模板化渲染方案

> 状态：待评估 · 暂不实现，保持现有纯 Prompt 生成方案
> 日期：2026-06-28

---

## 背景

当前精华卡通过单一 Prompt 让 LLM 直接生成完整 HTML，存在以下问题：

- 每次生成布局不一致，依赖 Prompt 约束效果有限
- 区块布局（列表/卡片/格子）由 LLM 自由发挥，难以保证多样性
- 设计迭代需要反复修改 Prompt + 重跑验证，成本高

---

## 目标方案：两步流水线（提取 → 模板渲染）

### 现状 vs 目标

| | 现在（纯 Prompt） | 目标（模板） |
|---|---|---|
| LLM 做什么 | 提取内容 + 生成完整 HTML | 只提取结构化 JSON |
| 布局一致性 | 每次不同，靠 Prompt 约束 | 100% 一致，由模板控制 |
| 迭代方式 | 改 Prompt，重跑验证 | 改模板 CSS/HTML，即时生效 |
| 区块变化 | LLM 自由发挥 | 模板固定，字段有则渲染无则跳过 |

## Step 2：Jinja2 模板渲染

模板文件 `content_card_template.j2`，每个区块固定布局，字段为空/null 时自动跳过：

| 区块 | 固定布局 |
|---|---|
| 1 Hero | 全宽直角、零外边距；两列参与者卡片（头像左列垂直居中 + 文字右列垂直居中）；主持徽章内联姓名右侧 |
| 2 核心主题 | 全宽深色大字卡，衬线字体，超大半透明引号装饰 |
| 3 核心洞察 | Bento 格子（2列），顶部金色序号 + 标题 + 说明 |
| 4 思维导图 | Mermaid `graph TD`，8-12节点 |
| 5 数据可视化 | Chart.js，flex横排，≤3个图表，canvas明确宽高 |
| 6 实用价值 | 根据 `actions.type` 自动切换：步骤流 / 横排卡片组 / 四象限 CSS 图 |
| 7 金句 | 层次递减大字引用：第1条全宽最大，后续略小，靠间距而非边框区分 |
| 8 延伸资源 | 2-3列格子，图标 + 标题 + 推荐理由 |
| 9 页脚 | 全宽直角、零外边距；左侧来源+参与者，右侧 inFlow AI 品牌 |
