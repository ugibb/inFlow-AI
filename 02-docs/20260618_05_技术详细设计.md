## 三、核心服务详细说明

### 3.1 AI Service（ai_service.py）

**初始化：**
- 启动时加载本地 fastembed 模型（`TextEmbedding("BAAI/bge-small-zh-v1.5")`）
- 支持动态切换到外部嵌入 API（通过 config_manager）

**主要方法：**

```python
# 生成本地嵌入（512 维）
async def generate_local_embedding(text: str) -> List[float]

# 生成嵌入（支持本地/云端切换，区分 document/query 模式）
async def get_embedding(text: str, emb_type: str = "document") -> List[float]

# AI 解析文章（摘要/标签/关键点/作者）
async def parse_article(
    text: str,
    url: str = "",
    raw_html: str = ""
) -> Dict  # 返回 title/summary/key_points/tags/source_platform/author

# 生成知识图谱边
async def generate_knowledge_graph(articles: List[Dict]) -> Dict

# 生成思维导图（递归树结构）
async def generate_mindmap(content: str, title: str) -> Dict

# AI 生成学习路径排序
async def generate_learning_path(topic: str, articles: List[Dict]) -> Dict

# 健壮 JSON 解析（多阶段修复）
def robust_json_parse(raw: str) -> Any
# 阶段1：直接 json.loads
# 阶段2：括号平衡修复
# 阶段3：json_repair 库修复
# 阶段4：提取第一个 JSON 对象/数组
```

**LLM 调用参数：**
- temperature: 0.3（摘要/图谱），0.7（Spark 创作）
- max_tokens: 2048（摘要），4096（Spark）
- 重试：3 次指数退避

### 3.2 Parser Service（parser_service.py）

**平台检测逻辑：**

```python
PLATFORM_PATTERNS = {
    'wechat':    ['mp.weixin.qq.com'],
    'toutiao':   ['toutiao.com'],
    'bilibili':  ['bilibili.com', 'b23.tv'],
    'douyin':    ['douyin.com', 'iesdouyin.com'],
    'xhs':       ['xiaohongshu.com', 'xhslink.com'],
    'zhihu':     ['zhihu.com'],
    'juejin':    ['juejin.cn'],
    'csdn':      ['csdn.net'],
    'medium':    ['medium.com'],
    'youtube':   ['youtube.com', 'youtu.be'],
    ...
}
```

**抓取策略：**

| 平台 | 策略 | 说明 |
|---|---|---|
| 微信公众号 | Playwright headless Chrome | 需要渲染 JS，处理防盗链 |
| 头条 | Playwright | 动态渲染 |
| 抖音 | 标记 ASR_PENDING | 视频平台，内容在音频 |
| B站 | Playwright + ASR | 视频字幕 + 评论 |
| 小红书 | curl_cffi | TLS 指纹绕过 |
| YouTube | yt-dlp + Whisper | 音频下载 + 本地转录 |
| 通用网页 | httpx + BeautifulSoup | 标准 HTTP 请求 |

**Markdown 清洗：**
- 去除导航/广告/版权声明
- 图片 URL 保留（后续通过代理访问）
- 代码块格式化
- 中文排版优化（标点、间距）

### 3.3 Graph Service（graph_service.py）

**知识边生成算法：**

```
1. 获取新文章的 tags 和 key_words
2. 查询候选文章：
   - 相同标签的文章（tag overlap）
   - 关键词命中的文章（plain_text ILIKE）
   - 排除自身，限制 20 篇
3. 构建 LLM Prompt：
   - 新文章摘要 + 候选文章摘要列表
   - 要求输出：edges（source_id, target_id, type, weight, desc）
4. 解析 LLM 输出，过滤无效边（ID 不在库中的）
5. 批量插入（ON CONFLICT DO NOTHING）
```

**关系类型语义：**
- `related`：内容相关，互相补充
- `prerequisite`：理解 source 需要先读 target
- `extends`：source 是 target 的延伸/深入
- `contradicts`：观点对立，可对比阅读

### 4.2 AddContentModal（多入口采集）

**四种入库模式（Tab 切换）：**

1. **URL 模式**
   - 文本域（支持多行粘贴，自动提取 URL）
   - 提交 → POST /api/articles

2. **粘贴正文模式**
   - URL 字段 + 标题字段 + 内容大文本域
   - 提交 → POST /api/articles/manual

3. **文件上传模式**
   - 拖拽或点击上传
   - 支持格式提示
   - 提交 → POST /api/articles/upload（FormData）

4. **Spark 模式**
   - 单行输入（一句话）

## 七、关键算法说明

### 7.1 向量相似度计算

```sql
-- 余弦距离（pgvector <=> 操作符，范围 0-2）
SELECT id, title,
       1 - (embedding <=> $1) AS relevance
FROM articles
WHERE user_id = $2
  AND embedding IS NOT NULL
ORDER BY embedding <=> $1
LIMIT $3;
```

相关度转换：`relevance = max(0, 1 - cosine_distance)`
- 1.0 = 完全相同
- 0.7+ = 高度相关
- 0.45- = 不相关（知识图谱生成时过滤阈值）

### 7.2 Keyset Pagination（Obsidian 同步用）

```python
# 游标格式："{updated_at ISO8601}|{uuid}"
# 查询：
WHERE (updated_at, id) > (cursor_ts, cursor_id)
ORDER BY updated_at ASC, id ASC
LIMIT limit
```

优势：比 OFFSET 分页更稳定，新增/删除不影响翻页一致性

### 7.3 Token 撤销机制

```python
# 签发同步 Token 时嵌入 token_version
payload = {
    "sub": user_id,
    "type": "sync",
    "token_version": user.sync_token_version
}

# 验证时检查版本
if payload["token_version"] != user.sync_token_version:
    raise HTTPException(401, "Token 已撤销")

# 撤销所有 Token：只需递增版本号
user.sync_token_version += 1
# 无需维护黑名单
```
