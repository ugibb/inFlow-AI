# Read 页按块补生成 + 顶部统一重生成 + 免费额度可配 上线记录

- **日期**：2026-09-03
- **状态**：已本地验证并推送（`429813d` → `origin/main`）；待人工按「五、部署步骤」上线
- **涉及站点**：`inflow.huituai.site`（代码直接部署形态）
- **背景**：三处交互/配置优化合并一次上线

---

## 一、需求（三句原话）

1. read 页需判断文章所有标签页内容是否都存在，只要有缺 → 显示「进度」栏，可独立补生成缺失块，无需整条链路重跑。
2. 「重新生成」按钮移到顶部 `<div class="flex items-center gap-1">`；每个标签页内容最下面加「重新生成」按钮，明确表示仅重新生成本章节。
3. 「今日免费额度（10 条）已用完，明天再来」改为系统管理可配置项，保存后立即生效。

**已确认决策**：顶部按钮合并为 1 个、全内容类型可用；缺失检测范围 = AI 块 + 原始抓取；quota = 开关 + 每日条数（默认 10，0 = 不限额）。

---

## 二、实现要点

| 项 | 内容 |
|---|---|
| **① content_blocks 快照** | `GET /articles/{id}` 新增 `content_blocks`：每块 `{applicable,present}`，按内容类型门控（audio 的 raw=节目信息 不可单独重生成 → 不参与进度） |
| **① 进度栏** | read 页任一适用块缺失即显示，指明缺哪块，进对应 tab 可单块补生成 |
| **② 新端点** | `POST /articles/{id}/regenerate-block`，body `{block}` ∈ raw/transcript/chapters/deepRead/ai |
| **② 同步/异步分流** | 文本类 `ai` 块云端**同步**重跑 LLM 解析（不重抓取、不动图谱）；其余块 + 音频 `ai` 把已结束 job 从 `capturing/transcribing/parsing/composing` 对应入口 `resume_for_retry`，交本地 worker 补齐 |
| **② UI** | 顶部 1 个「重新生成」（audio→重解析、图文→云端重解析）；每 tab 底部「仅重新生成××」 |
| **③ quota 可配** | 配置 schema 新增 `quota` 组（icon=gauge），`enabled` 开关 + `limit_per_day`；`get_quota_limit()` 每次现读 config JSON → UI 保存后**下一条入库请求即生效，无需重启** |

## 五、部署步骤（需人工，宝塔/控制台执行）

```bash
# 1. 进服务器该网站仓库目录
cd /你的/inflow-ai/仓库目录

# 2. 拉取代码
git pull

# 3. 标准入口：重建前端镜像 + 重启直跑 backend/bot（后台，不占终端）
./start-server.sh --restart --detach

# 4. 健康检查（可选）
curl -s http://127.0.0.1:8080/api/health
```

前端为 Docker 镜像，第 3 步自动 `build frontend`（约 1–3 分钟）。**worker（本机 Mac inflow-worker）无需升级**，但要保持常驻 —— 单块续跑类依赖它认领 job。

## 六、验收清单

1. **浏览器硬刷新**（Cmd/Ctrl+Shift+R）打开 read 页：顶部只剩 1 个「重新生成」；每 tab 底部有「仅重新生成××」。仍见旧 UI → 浏览器/宿主 nginx 缓存，按 `20260902_宿主Nginx全局缓存…` 记录二次分诊（inflow 站点 `proxy_cache off` 已固化，一般不会命中）。
2. **进度栏**：找缺章节/缺精读的文章 → 出现进度栏并指出缺哪块；点缺块「仅重新生成」，audio 类提示「已开始…完成后自动刷新」，图文 `ai` 块即时完成。
3. **quota 可配**：系统管理出现「入库免费额度」组；改条数保存，**不重启**去新增一条内容验证按新值拦截/放行。

## 七、回滚与注意

- **回滚点**：`git reset --hard 5d6cee3`（上一 commit）后重跑 `./start-server.sh --restart --detach`。
- **quota 语义**：系统管理**首次保存前**额度仍走 `FREE_QUOTA_PER_DAY`（10，与线上现状一致）；首次保存 quota 组后由 UI 配置接管。
- **regenerate-block 语义**：只回写被点的那一块（`ai` 云端同步不动正文/图谱；worker 续跑类不改写其它块内容）。
